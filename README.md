Generate tailored cover letters with AI

## Install

```bash
npm install -g ai-cover-letter
```

## Usage

```bash
npx ai-cover-letter "frontend role at Stripe"
npx ai-cover-letter "senior backend engineer at Vercel"
```

## Setup

```bash
export OPENAI_API_KEY=sk-...
```
